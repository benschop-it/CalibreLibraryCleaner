# Documentation Archive

This directory contains completed or superseded milestone plans and handoffs.

Archived documents are historical evidence, not current product requirements or
architecture. They may describe removed backup, execution, rollback, recovery,
composite cleanup, cancellation, persistence, or matching behavior.

Use the current documents linked from [docs/README.md](../README.md) and the newest
accepted ADR when historical material conflicts with current direction.
